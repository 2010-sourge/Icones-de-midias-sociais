# 🔗 Social Media Buttons — Neumorphism

Cinco botões de redes sociais com efeito **neumorfismo** (neumorphism), desenvolvido com HTML e CSS puro.

---

## 📸 Preview

> Cinco botões circulares lado a lado sobre fundo cinza claro, com efeito de relevo/sombra neumórfico. Ícones de Facebook, Twitter, Instagram, GitHub e YouTube nas cores oficiais de cada plataforma.

---

## 🚀 Tecnologias

- **HTML5**
- **CSS3**
- **Font Awesome** (ícones das redes sociais)

---

## 📁 Estrutura do Projeto

```
social-media-buttons/
├── index.html
└── style.css
```

---

## ⚙️ Como Executar

1. Clone o repositório:
   ```bash
   git clone https://github.com/seu-usuario/social-media-buttons.git
   ```

2. Acesse a pasta do projeto:
   ```bash
   cd social-media-buttons
   ```

3. Abra o `index.html` diretamente no navegador ou via **Live Server** no VS Code:
   - Acesse em: `http://127.0.0.1:5500`

---

## 🎯 Funcionalidades

- 5 botões circulares com efeito neumórfico (sombra dupla: clara e escura)
- Efeito de pressão ao clicar (inset shadow)
- Ícones nas cores oficiais de cada rede social
- Links para redirecionamento às redes sociais

---

## 🎨 Design — Neumorphism

- Fundo da página: cinza claro (`#e0e0e0` aprox.)
- Botões: mesmo tom do fundo com sombras duplas (clara + escura) criando efeito de relevo
- Hover/Active: sombra invertida simulando pressão
- Bordas: totalmente arredondadas (círculos perfeitos)

---

## 📌 Observações

- Projeto estático, sem dependências além do Font Awesome (via CDN)
- Ideal como componente de rodapé ou perfil em portfólios e landing pages
